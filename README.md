# Монтажные ведомости ОВиК (Go)

Первый проверяемый срез разработки: HTTP-сервер, тесты и черновая схема PostgreSQL.
Это **не законченный продукт**: нет подключённого репозитория PostgreSQL, аутентификации,
редактора ведомости, расчётного движка, импорта и экспорта XLSX.

## Требования

- Go 1.23+ для проверки этого начального среза; целевой стек продукта — Go 1.25+.
- PostgreSQL 17+ (через Docker Compose или локально).
- `golang-migrate` для применения SQL миграций (в этой итерации не установлен автоматически).

## Локальный запуск сервера

```sh
go test ./...
go run ./cmd/server
curl -i http://localhost:8080/healthz
curl -i http://localhost:8080/readyz
```

`/healthz` возвращает 200; `/readyz` намеренно возвращает 503, так как подключения
к БД пока нет. Это не фиктивная готовность приложения.

## PostgreSQL

```sh
cp .env.example .env
# замените секрет в .env на свой
make db-up
# после установки golang-migrate:
migrate -path migrations -database "$DATABASE_URL" up
```

Миграции требуют PostgreSQL 17. Они ещё не проверены на живой БД в текущей среде.
Настоящая авторизация, разграничение доступа, immutable snapshots, Calculation Engine и
идемпотентный XLSX-экспорт добавляются следующими отдельными этапами.
